## Getting Started

Most projects here are static and run directly in the browser:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
# open the relevant project's index.html in your browser
```

Projects using Bower dependencies (`bower_components/`) require [Bower](https://bower.io/) — dependencies are not committed to this repo, so run:

```bash
npm install -g bower
bower install
```
